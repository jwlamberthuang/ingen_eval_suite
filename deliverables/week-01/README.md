# Week 1 review package

Week 1 establishes the evaluation design and initial bilingual dataset.

| Deliverable | Review artifact |
| --- | --- |
| Evaluation framework | [Word](../../docs/W01_InGen_AI_Evaluation_Framework.docx) and [Markdown](../../docs/evaluation_framework.md) |
| Dataset specification | [Word](../../docs/W01_Dataset_Specification.docx) and [Markdown](../../docs/dataset_specification.md) |

The collection has 40 Fari English, 20 Fari Chinese, 25 Senpai English, and 15
Senpai Chinese cases. All reviewed dialogue is preserved. The metadata integrity
repair and updated validation evidence are included in the
[Week 2 review package](../week-02/README.md).

Shared code, schemas, and datasets retain their canonical locations. This index
is the single review entry point for the week's artifacts.
